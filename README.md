# BrandForge AI

BrandForge AI is an AI-powered startup branding tool that generates startup names, taglines, and domain suggestions instantly.

# Features

- AI Generated Startup Names
- Unique Taglines
- Domain Suggestions
- Copy to Clipboard
- Responsive Design
- Generate More Ideas

# Tech Stack

- React.js
- JavaScript
- OpenRouter API
- Axios
- HTML5 & CSS3
- Vite
- GitHub
- Vercel

```bash
git clone https://github.com/gauravv443/BrandForge-AI.git
cd BrandForge-AI
npm install
npm run dev
```
